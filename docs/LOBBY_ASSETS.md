# Lobby background asset

`Assets/_Project/Resources/Backgrounds/lobby.jpg` is a locally bundled Unsplash photograph used by the existing `LobbyBackground` image layer. It is not loaded from the network at runtime.

- Source: https://images.unsplash.com/photo-1519501025264-65ba15a82390
- License: Unsplash License, https://unsplash.com/license
- Optimized to 1920x1080 JPEG for the lobby backdrop.

The asset is a replaceable visual placeholder. Replace the file with original Noxy environment art when ready; keep the `lobby` resource key so the fallback and cross-fade behavior remain unchanged.
